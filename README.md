# Bathrooms Scotland

A modern, mobile-friendly starter website for a Scotland-based bathroom planning and installation business.

## Preview
Open `index.html` in a browser. This starter uses plain HTML, CSS and JavaScript, so no package installation or build step is needed.

## Editing with Codex
Open this repository in Codex and ask for changes in everyday language. Codex should read `AGENTS.md` first, then edit, test and commit the changes to GitHub.

## Deploying with Vercel
Import this GitHub repository into Vercel as an **Other** framework/static site. Set the root directory to the repository root and leave the build command empty. Enable Git deployments. Vercel settings must be confirmed in the Vercel dashboard; this repository alone cannot connect an account.

## Before launch
Replace placeholder company name, contact email, phone, service areas, images and claims with verified business details. Connect a real contact form provider or backend before promising form submissions. Test on mobile and desktop.

## Saving future changes safely
- Read AGENTS.md before editing and preserve existing work.
- Start a feature branch from the latest main, commit every intended file, and push the branch to this repository.
- Open a pull request and report its URL and commit SHA. Local workspace edits alone are not a GitHub backup.
- Check the Vercel preview status for the pull request. After an approved merge to main, verify the production deployment and live website.
- Never commit credentials or environment secrets. Do not change billing or domains without the owner's approval.

## Vercel settings to verify
For this static site, use Framework Preset **Other**, the repository root, no build command, no install command, and serve the repository root (no generated dist directory is required). Production should track **main** with Git deployments enabled. These are expected settings, not a claim that the dashboard has been inspected.
